# News Rules

이 문서는 하단 뉴스/공시 이슈 바와 종목 Overview 뉴스 영역의 필터링 기준을 정의한다.
뉴스와 공시는 사용자의 현재 선택 상태에 맞춰 정보 과부하를 줄이는 보조 맥락으로 사용한다.

## 데이터 소스

- 한투 OpenAPI에서 제공 가능한 시황, 공시, 뉴스성 데이터를 우선 사용한다.
- 부족한 경우 KIND, DART, 외부 뉴스 API 또는 별도 수집 데이터를 사용할 수 있다.
- 모든 뉴스/공시 항목은 제목, 시간, 관련 대상, 태그, 원문 식별자를 보존한다.

## 뉴스 바 필터링

- 전체 시장 상태에서는 시장 전체 관련 뉴스와 주요 공시를 표시한다.
- 섹터 선택 상태에서는 해당 섹터 관련 뉴스와 섹터 내 주요 종목 공시를 표시한다.
- 종목 선택 상태에서는 해당 종목 뉴스와 공시를 우선 표시한다.
- 전체 시장 상태에서는 뉴스 목록보다 시장 이슈 키워드를 먼저 보여줄 수 있다.
- 종목 Overview 상태에서는 하단 뉴스 바보다 Overview 내부 뉴스/공시 섹션을 우선한다.

## 뉴스 우선순위

1. 선택 대상과 직접 관련된 뉴스 또는 공시
2. 선택 대상과 같은 섹터의 뉴스
3. 거래대금 상위 종목 관련 뉴스
4. 주요 공시
5. 시장 전체 뉴스

## 관련도 매칭 규칙

- 종목 상태에서는 `stock_code` 직접 매칭을 최우선으로 한다.
- 종목코드가 없으면 종목명, 별칭, 회사명 키워드로 매칭한다.
- 섹터 상태에서는 섹터명, 산업명, 대표 키워드로 매칭한다.
- 전체 시장 상태에서는 지수, 시장, 금리, 환율, 반도체, 2차전지 등 시장성 키워드를 사용한다.
- 동일 제목 또는 같은 URL의 뉴스는 중복 제거한다.

## 태그 규칙

- 뉴스/공시는 최대 3개의 태그를 가진다.
- 태그는 섹터, 종목, 이슈 키워드 순서로 부여한다.
- 예: `#반도체`, `#HBM`, `#공시`

## 표시 제한

- 하단 뉴스 바는 기본 5개까지 표시한다.
- 종목 Overview 하단 뉴스 영역은 기본 5~10개까지 표시한다.
- 최신순을 기본으로 하되, 직접 관련도가 높은 항목을 최신 시장 뉴스보다 우선할 수 있다.
- 하단 뉴스 바는 최대 3~5개만 한 줄로 표시한다.
- 긴 제목은 말줄임 처리하고, 상세 내용은 클릭 또는 확장 영역에서 보여준다.
- 뉴스 항목은 `시간 · 유형 · 태그 · 제목` 순서로 작게 표시한다.
- 뉴스 바는 주요 히트맵 또는 차트를 덮지 않는다.
- fixed bottom 카드 형태는 기본으로 사용하지 않는다.

## fallback 규칙

- 직접 관련 뉴스가 없으면 같은 섹터 뉴스를 표시한다.
- 같은 섹터 뉴스도 없으면 거래대금 상위 종목 또는 시장 전체 뉴스를 표시한다.
- 표시할 항목이 전혀 없으면 "현재 선택 대상과 직접 연결된 뉴스가 없습니다."를 표시한다.

## 인사이트 연결 원칙

- 뉴스나 공시는 상승/하락 원인으로 확정하지 않는다.
- 문구는 "관련 이슈로 확인됩니다", "원인 후보로 볼 수 있습니다", "확인이 필요합니다"처럼 표현한다.
- 위험 공시, 실적 악화, 유상증자, 전환사채 등은 주의 태그를 붙일 수 있다.
