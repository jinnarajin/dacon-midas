# Stock Overview Rules

이 문서는 종목 클릭 후 진입하는 종목 Overview 화면의 표시 규칙과 인사이트 기준을 정의한다.
종목 Overview는 단순 카드가 아니라 핵심 지표, 차트, 뉴스/공시, 섹터 대비 성과를 한 화면에 연결하는 상세 분석 화면이다.

## 진입 규칙

- 사용자가 섹터 맵 또는 종목 맵에서 종목을 클릭하면 종목 Overview 화면으로 전환한다.
- Overview 상태의 선택 모델은 `selectedLevel = stock`, `selectedStockCode = <종목코드>`로 둔다.
- 사용자가 뒤로 가거나 섹터를 다시 선택하면 섹터 인사이트 상태로 돌아간다.

## 핵심 표시 항목

- stock_name
- stock_code
- market
- sector
- industry
- current_price
- change_rate
- volume
- trading_value
- volume_growth_rate
- sector_avg_change_rate
- excess_return
- volatility
- related_news
- related_disclosures

## 상단 요약 규칙

- 종목명, 종목코드, 시장, 섹터를 먼저 표시한다.
- 현재가와 등락률을 가장 잘 보이는 위치에 둔다.
- 거래량, 거래대금, 거래량 증가율은 시장 관심도 판단 지표로 묶어 표시한다.
- 섹터 평균 대비 성과는 `excess_return`으로 표시한다.
- Overview 상단은 좌측에 `종목명 / 현재가 / 등락률`을 크게 배치한다.
- `거래량`, `거래대금`, `섹터 대비`, `변동성`은 compact KPI로 묶어 우측 또는 하단에 배치한다.
- KPI는 카드처럼 크게 띄우지 않고 숫자 중심의 작은 블록으로 표시한다.
- 선택한 종목은 히트맵 안에서도 selected 상태로 유지 표시한다.

## 차트 규칙

- 가격 차트는 기본적으로 최근 1개월 일봉 데이터를 표시한다.
- 기간 선택은 `1D`, `1W`, `1M`, `3M`, `1Y`를 제공한다.
- 차트 하단에는 거래량 막대를 함께 표시한다.
- 일봉 데이터가 부족하면 사용 가능한 기간만 표시한다.
- 확장 기능으로 캔들 차트, 이동평균선, 보조지표를 추가할 수 있다.
- 종목 Overview에서 차트는 화면의 중심 요소이다.
- 뉴스와 지표는 차트를 밀어내지 않고 보조 영역으로 배치한다.
- 데스크톱에서는 차트가 Overview 영역 가로폭의 최소 50% 이상을 차지한다.
- 모바일에서는 종목 요약, 차트, 뉴스 순서로 세로 배치한다.

## 종목 인사이트 규칙

| 조건 | 표시 문구 방향 |
| --- | --- |
| 종목 등락률이 섹터 평균보다 +2%p 이상 | 섹터 대비 강세 |
| 종목 등락률이 섹터 평균보다 -2%p 이하 | 섹터 대비 약세 |
| 거래량 증가율 100% 이상 | 시장 관심도 증가 |
| 거래대금 상위 10% 진입 | 수급 집중 후보 |
| 단기 변동성이 최근 평균 대비 1.5배 이상 | 변동성 유의 |
| 관련 뉴스 존재 | 상승/하락 원인 후보 확인 |
| 관련 공시 존재 | 기업 이벤트 확인 필요 |

## 뉴스/공시 표시 규칙

- 종목 관련 뉴스와 공시는 Overview 하단에 표시한다.
- 공시는 뉴스보다 우선 표시할 수 있다.
- 종목코드 직접 매칭 공시가 있으면 "기업 이벤트 확인 필요" 문구를 연결한다.
- 관련 뉴스가 없으면 같은 섹터 뉴스로 fallback한다.
- 종목 뉴스는 큰 카드 5개 나열보다 `공시 우선 + 관련 뉴스 리스트`로 작게 정리한다.
- 뉴스 항목은 `시간 · 유형 · 태그 · 제목` 순서로 표시한다.
- 종목 Overview 상태에서는 하단 fixed 뉴스 바보다 내부 뉴스 섹션을 우선한다.
- 관련 공시는 뉴스 리스트 상단에 배치하고 `공시 확인` 상태 라벨을 붙인다.

## 화면 위계

- 현재가와 차트가 가장 먼저 읽혀야 한다.
- 섹터 대비 성과와 거래량 증가율은 두 번째 위계로 둔다.
- 뉴스와 공시는 세 번째 위계로 둔다.
- Overview가 히트맵보다 아래에 있을 경우 사용자가 선택한 종목 맥락을 잃지 않도록 종목명과 섹터명을 반복 표시한다.

## 문장 생성 예시

```text
[강세] SK하이닉스는 반도체 섹터 평균보다 높은 상승률을 기록하고 있습니다.
근거: 거래량 증가율 100% 이상, 섹터 대비 초과 상승률 +2%p 이상.
확인: HBM, AI 서버 관련 뉴스는 원인 후보로만 연결합니다.
```

## 금지 원칙

- 투자 추천 표현은 사용하지 않는다.
- 특정 뉴스나 공시를 상승/하락 원인으로 단정하지 않는다.
- 데이터가 부족한 지표는 숨기거나 "데이터 부족"으로 표시한다.
