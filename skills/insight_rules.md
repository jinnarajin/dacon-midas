# Insight Rules

이 문서는 전체 시장, 섹터, 종목 Overview에서 생성하는 인사이트 기준을 정의한다.
인사이트는 AI가 임의로 단정하는 문장이 아니라, 지표와 뉴스/공시 조건을 바탕으로 생성하는 참고 정보이다.

## 인사이트 단계

1. 선택 대상이 없으면 전체 시장 인사이트를 생성한다.
2. 섹터가 선택되면 현재 섹터 인사이트를 생성한다.
3. 종목이 선택되면 종목 Overview 인사이트를 생성한다.

## 표현 원칙

- 투자 추천 표현을 사용하지 않는다.
- 매수, 매도, 보유, 목표가, 확정 수익 같은 표현을 사용하지 않는다.
- 상승/하락 원인은 확정하지 않고 "후보", "가능성", "확인 필요"로 표현한다.
- 데이터 근거를 함께 제시한다.
- 과열, 변동성, 공시 확인 필요 여부를 함께 표시한다.
- 뉴스나 공시가 있어도 인과관계를 단정하지 않는다.
- 사용자 화면에는 `Harness Rules`, `규칙 적용`, `LLM`, `프롬프트`, `mock` 같은 내부 구현 설명을 노출하지 않는다.

## UI 출력 구조

- 인사이트는 `한 줄 결론 + 근거 지표 2개 + 확인 필요 이슈 1개` 구조를 기본으로 한다.
- 긴 문단 대신 compact insight row 또는 짧은 bullet로 표시한다.
- 각 인사이트 row는 상태 라벨을 먼저 보여준다.
- 상태 라벨은 `강세`, `약세`, `관심 증가`, `변동성 유의`, `공시 확인`, `혼조`, `데이터 부족` 중 하나를 우선 사용한다.
- 한 화면에서 인사이트는 기본 3개, 최대 5개까지만 노출한다.
- 하나의 인사이트 문장은 2줄을 넘지 않게 한다.

## 전체 시장 인사이트 규칙

| 조건 | 인사이트 방향 |
| --- | --- |
| 상승 종목 비율 60% 이상 | 시장 전반 강세 |
| 하락 종목 비율 60% 이상 | 시장 전반 약세 |
| 특정 섹터 거래대금이 전체 거래대금의 25% 이상 | 해당 섹터 주도 장세 후보 |
| 특정 섹터 평균 등락률이 시장 평균보다 +2%p 이상 | 섹터 상대 강세 |
| 변동성이 최근 평균 대비 1.5배 이상 | 리스크 확대 |
| 대형주 중심 상승, 상승 종목 비율 50% 미만 | 제한적 강세 가능성 |
| 중소형주와 대형주가 함께 상승 | 시장 확산 가능성 |

## 섹터 인사이트 규칙

| 조건 | 인사이트 방향 |
| --- | --- |
| 섹터 평균 등락률이 시장 평균보다 높음 | 섹터 상대 강세 |
| 섹터 내 상승 종목 비율 60% 이상 | 섹터 동반 상승 |
| 대표 종목 거래대금 증가율 100% 이상 | 주도주 중심 관심 증가 |
| 일부 종목만 상승하고 상승 종목 비율 40% 미만 | 개별 이슈 가능성 |
| 섹터 변동성이 최근 평균 대비 1.5배 이상 | 단기 과열 또는 리스크 확대 |
| 섹터 내 하락 종목 비율 60% 이상 | 섹터 약세 가능성 |

## 종목 Overview 인사이트 규칙

| 조건 | 인사이트 방향 |
| --- | --- |
| 종목 등락률이 섹터 평균보다 +2%p 이상 | 섹터 대비 강세 |
| 종목 등락률이 섹터 평균보다 -2%p 이하 | 섹터 대비 약세 |
| 거래량 증가율 100% 이상 | 시장 관심도 증가 |
| 거래대금 상위 10% 진입 | 수급 집중 후보 |
| 섹터도 함께 상승 | 섹터 동반 효과 가능성 |
| 종목만 단독 상승 | 개별 뉴스 또는 공시 확인 필요 |
| 변동성이 최근 평균 대비 1.5배 이상 | 단기 리스크 확대 |
| 관련 공시 존재 | 기업 이벤트 확인 필요 |

## 문장 생성 규칙

- 첫 문장은 선택 대상의 현재 상태를 짧게 요약한다.
- 둘째 문장은 근거 지표 1~2개를 포함한다.
- 셋째 문장은 뉴스, 공시, 키워드 같은 외부 맥락을 연결하되 생략할 수 있다.
- 마지막 문장은 필요한 경우 변동성, 과열, 공시 확인 등 유의 문구를 넣는다.
- UI 카드 안에서는 4문장 문단을 그대로 노출하지 않고 핵심 row로 분리한다.

## 예시 톤

```text
[강세] 반도체 섹터는 시장 평균보다 높은 상승률을 보입니다.
근거: 상승 종목 비율 60% 이상, 주요 대형주 거래대금 증가.
확인: HBM, AI 서버 키워드는 원인 후보로만 연결합니다.
```

## 금지 표현

- "매수하세요"
- "지금 사야 합니다"
- "상승이 확정됐습니다"
- "수익이 예상됩니다"
- "하락 원인은 이것입니다"
