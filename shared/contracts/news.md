# News Contract

This document defines the shared response shape for news, disclosures, and reports.

Endpoint:

```http
GET /api/news
```

Used by:

- `NewsDock`
- market-level `related_news_ids`
- sector-level `related_news_ids`
- stock-level `related_news_ids`
- stock-level `related_disclosure_ids`

## Query Parameters

- `selection_level`: one of `"market"`, `"sector"`, `"stock"`.
- `market`: optional market universe. MVP uses `"KR"`.
- `sector_id`: required when `selection_level` is `"sector"` or `"stock"`.
- `stock_code`: required when `selection_level` is `"stock"`.
- `limit`: optional item count. Backend default is `20`.

## Response Shape

```json
{
  "selection": {
    "level": "stock",
    "market": "KR",
    "sector_id": "information-technology",
    "stock_code": "000660"
  },
  "as_of": "2026-05-10 15:30:00",
  "items": [
    {
      "id": "news-20260510-021",
      "item_type": "news",
      "title": "Memory stocks rise on AI server demand expectations",
      "source": "Example News",
      "published_at": "2026-05-10 10:07:00",
      "url": "https://example.com/news/20260510-021",
      "summary": "information-technology names moved higher as investors focused on AI server demand.",
      "related_market": "KR",
      "related_sector_ids": ["information-technology"],
      "related_stock_codes": ["000660"],
      "tags": ["HBM", "AI server"],
      "priority": 1,
      "is_direct_match": true
    },
    {
      "id": "disclosure-20260510-005930-001",
      "item_type": "disclosure",
      "title": "Samsung Electronics facility investment disclosure",
      "source": "KIND",
      "published_at": "2026-05-10 09:42:00",
      "url": "https://example.com/disclosure/20260510-005930-001",
      "summary": null,
      "related_market": "KR",
      "related_sector_ids": ["information-technology"],
      "related_stock_codes": ["005930"],
      "tags": ["disclosure", "investment"],
      "priority": 2,
      "is_direct_match": false
    }
  ],
  "empty_state": null
}
```

## Field Rules

### `selection`

- Mirrors the current UI selection state.
- `sector_id` is null or omitted for market-level requests.
- `stock_code` is null or omitted unless the request is stock-level.

### `as_of`

- Format: `YYYY-MM-DD HH:mm:ss`.
- Represents when news/disclosure data was last collected or refreshed.

### `items`

- Sorted by relevance first, then by `published_at` descending.
- Must include both direct and contextual items when useful.
- Must not include duplicate items with the same title and source.

### `id`

- Stable item identifier generated by the backend.
- Recommended pattern:
  - `news-YYYYMMDD-sequence`
  - `disclosure-YYYYMMDD-stockCode-sequence`
  - `report-YYYYMMDD-sequence`

### `item_type`

Allowed values:

- `"news"`
- `"disclosure"`
- `"report"`

### `source`

- User-facing source name.
- Examples: `"KIND"`, `"DART"`, `"KRX"`, or a news provider name.

### `published_at`

- Format: `YYYY-MM-DD HH:mm:ss`.
- Use the original publication time when available.

### `url`

- Original source URL when available.
- Can be null only when the source does not provide a public link.

### `summary`

- Short backend-provided summary or null.
- Must not contain investment recommendation wording.

### `related_market`, `related_sector_ids`, `related_stock_codes`

- Used for filtering by selection state.
- `related_sector_ids` can contain multiple sector tags.
- `related_stock_codes` can be empty for market-wide or sector-wide items.

### `tags`

- Short user-facing tags.
- Must not expose internal labels such as rule names, prompt names, or mock/test wording.

### `priority`

- Lower number means higher display priority.
- Direct stock disclosure should rank higher than broad sector commentary in stock-level views.

### `is_direct_match`

- True when the item directly matches the current selection.
- False when the item is contextual, such as sector news shown in a stock view.

### `empty_state`

- Null when `items` is not empty.
- When no item exists, return:

```json
{
  "message": "No directly related news or disclosures are available for the current selection.",
  "reason": "no_items"
}
```

- `selection.level`
